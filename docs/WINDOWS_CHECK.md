# Windows 실기 확인 키트

Windows PC에서 사람이 직접 봐야만 아는 것을 순서대로 확인합니다. (검수 보고서 BE-14·BE-11·UX-30·BE-01(Windows)·RL-10·RL-19·UX-14 확인용)
릴리스 베타를 설치한 PC에서 하며, [릴리스 체크리스트](RELEASE_CHECKLIST.md) 3번과 함께 쓸 수 있습니다.

- 확인한 날짜 / 앱 버전 / Windows 버전 / PowerPoint 버전 / 화면 해상도·배율을 아래 '기록'에 먼저 적습니다.
- 각 항목의 **결과** 칸에 `O`(예상대로) / `X`(다름) / 메모를 적고, `X`면 화면 캡처를 남깁니다.

## 1. 줄바꿈 예측 vs PowerPoint 실제

앱은 가사 한 줄이 PPT 글상자 폭을 넘어 두 줄이 될지 미리 계산해 경고를 보여 줍니다. 이 계산 규칙은 Mac PowerPoint에서만 확인했으므로 Windows PowerPoint와 같은지 봅니다.

### 1-1. 시험 PPT 만들기 (개발 PC 또는 Windows에서)

프로젝트 루트에서:

```bash
python scripts/make_check_ppt.py -o windows_check.pptx
```

- 콘솔에 경계 줄 목록(번호·비율·예측)이 출력됩니다. 템플릿 글꼴이 없으면 '어림값' 경고가 나옵니다 — 이 경우 예측이 부정확하니 `assets/fonts`의 Pretendard를 설치한 PC에서 다시 만드세요.
- 만들어진 PPT: 1번 슬라이드는 전체 예측 요약, 그 뒤 경계 줄 슬라이드(한 슬라이드에 한 줄), 마지막 3장은 3·4·5줄 슬라이드입니다.
- 각 슬라이드 아래의 글자(초록 = 줄바꿈 안 함 예상, 빨강 = 예상)와 슬라이드 노트에 앱이 예측한 비율이 적혀 있습니다. 가사 글상자에는 가사 줄만 들어 있습니다.

### 1-2. Windows PowerPoint에서 비교

1. `windows_check.pptx`를 **Windows PowerPoint**에서 엽니다 (보호된 보기면 '편집 허용').
2. 글꼴이 Pretendard로 보이는지 확인합니다. 대체 글꼴로 보이면 결과가 달라지니 Pretendard(`assets/fonts`)를 설치하고 PowerPoint를 다시 엽니다.
3. 슬라이드 2번부터 차례로 보며 가사가 **한 줄이면 O, 두 줄 이상이면 X**로 적고, 앱 예측과 다르면 '불일치'에 표시합니다. (번호는 콘솔·요약 슬라이드의 번호 + 1)

## 3. 배율 150%·1366×768에서 화면

Windows 설정 → 시스템 → 디스플레이에서 해상도 **1366×768**, 배율 **150%**로 맞춥니다. (실제 PC가 없으면 해당 설정이 가능한 화면에서 근사값으로, 가상 머신이면 1366×768 + 150%)

앱 창은 기본 1100×800(논리 픽셀), 최소 900×560이지만 작은 화면에서는 작업 영역의 92%×90%까지 줄여 가운데에 열립니다(최소 크기도 같은 한도로 낮아짐). 150%에서 1366×768은 논리 픽셀로 약 911×512(작업 영역은 이보다 작음)라 창이 그에 맞춰 줄어 열립니다.

| 확인 | 결과 |
|---|---|
| 앱을 실행했을 때 창이 화면 안에 들어옴 (창 아래가 작업 표시줄 밑으로 잘리지 않음) | |
| 검색 화면이 잘리지 않음 | |
| 편집 화면에서 `PPT 생성` 버튼이 보임 (스크롤·창 이동 없이) | |
| 창을 최대화하면 모든 것이 보임 | |
| 튜토리얼(`?`)의 안내 상자가 화면 밖으로 나가지 않음 | |

## 4. 자동 업데이트

이전 베타가 설치된 PC에서 새 베타로 업데이트합니다. ([릴리스 체크리스트](RELEASE_CHECKLIST.md) 2번과 같이 진행)

### 4-1. 업데이트 설치 화면

업데이트 버튼을 누른 뒤 관찰합니다.

| 확인 | 결과 |
|---|---|
| 진행률이 보임 | |
| 앱이 닫힌 뒤 설치 마법사·검은 창·경고 창이 **보이지 않음** (`/VERYSILENT`) | |

| 다시 켜진 뒤 버전이 새 버전 | |
| Windows 보안 경고(SmartScreen·UAC)가 뜸 / 안 뜸 | |

### 4-2. 업데이트 후 저장 창 기본 폴더

저장 창의 기본 폴더는 '마지막으로 저장한 폴더'(앱을 켜 둔 동안만 기억)이고, 없으면 문서 폴더입니다. 업데이트로 앱이 다시 켜진 직후에는 마지막 폴더 기록이 없어 문서 폴더여야 하며, **설치 폴더(`%LOCALAPPDATA%\Programs\...`)가 나오면 안 됩니다.**

1. 업데이트 후 다시 켜진 앱에서 곡을 열고 `PPT 생성`을 누릅니다.
2. 저장 창이 처음 열린 폴더와 파일 이름을 적습니다.
3. 바탕화면 등 다른 폴더에 한 번 저장한 뒤 `PPT 생성`을 다시 누르면 그 폴더가 열리는지 확인합니다.

| 확인 | 결과 |
|---|---|
| 업데이트 직후 저장 창 폴더 | |
| 설치 폴더가 아님 | |
| 다른 폴더에 저장한 뒤 다음 저장 창이 그 폴더 | |

## 5. 실행 중 제거

1. 앱을 실행한 채(곡을 열어 편집 화면까지) 설정 → 앱 → 설치된 앱에서 'Lyrics Slide Creator'를 제거합니다.
2. 제거 과정과 끝난 뒤를 확인합니다.

| 확인 | 결과 |
|---|---|
| 제거 중 '앱이 실행 중이니 닫아 달라'는 안내가 뜨거나 앱이 자동으로 닫힘 | |
| 제거가 끝까지 완료됨 (오류·멈춤 없음) | |

| 제거 후 재부팅 요구가 뜸 / 안 뜸 | |

## 6. 한글 IME 조합 중 검색 버튼 클릭

한글 입력기(Microsoft IME)를 켠 상태에서:

1. 검색 화면의 입력칸에 **최유리**를 쳐서 마지막 글자 '리'가 **조합 중(밑줄)**인 상태로 둡니다. (Enter·스페이스는 누르지 않음)
2. 마우스로 검색 버튼(돋보기)을 클릭합니다.
3. 같은 방식으로 'ㅊ', '최유', '최유리'를 각각 조합 중 상태에서 검색 버튼을 눌러 봅니다.

| 확인 | 결과 |
|---|---|
| 검색어가 '최유리'로 검색됨 (마지막 글자 '리'가 빠지지 않음) | |
| 검색어가 '최유'만 검색됨 / 중복 입력 / 글자 깨짐 | |
| 검색 후 입력칸의 글자가 그대로임 | |
| Enter로 검색해도 같음 | |
