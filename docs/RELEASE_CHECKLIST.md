# 릴리스 체크리스트

태그를 올리면 GitHub Actions가 **초안(Draft) 릴리스**를 만듭니다. 아래 항목을 초안의 파일로 직접 확인한 뒤 **Publish release**를 누릅니다. 공개 전까지는 사용자에게 보이지 않고, 앱도 업데이트 대상으로 보지 않습니다.

CI가 이미 자동으로 확인한 것: 빌드, 화면·폰트·템플릿 로드(`--self-test`), Windows 설치 → 실행 → 제거 후 남은 파일 없음.
여기서는 **사람이 실제로 써봐야 아는 것**을 확인합니다.

## 0. 준비

- [ ] [Releases](https://github.com/seungheony/lyricsSlide_Creator/releases)에서 초안 릴리스를 열고 파일 3개(`-Setup.exe`, `-macOS.zip`, `SHA256SUMS.txt`)가 있는지 확인
- [ ] 릴리스 노트를 읽어보고 사용자가 이해할 수 있는 문장인지 확인 (앱 업데이트 창에 그대로 표시됨, 초안에서 수정 가능)

## 1. Windows

- [ ] `-Setup.exe` 실행 → ("Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행) → 설치 완료 후 앱이 켜짐
- [ ] 오른쪽 위 버전 표시가 태그와 같음 (예: `v1.2.0`)
- [ ] 검색 → 결과에 앨범아트가 보임
- [ ] 곡 선택 → 편집 화면: 가사가 2줄씩 나뉘어 있음
- [ ] 편집: 줄 사이 ✂ 나누기, 슬라이드 사이 합치기, 줄 드래그로 옮기기, 슬라이드 삭제, ⌘Z/Ctrl+Z 되돌리기
- [ ] 템플릿 `변경` → 다른 `.pptx` 선택이 됨
- [ ] `PPT 생성` → 저장 창에서 저장 → 완료 알림
- [ ] 만든 PPT를 PowerPoint에서 열어 가사·줄 간격·Pretendard 서체 확인 (가능하면 Pretendard가 없는 PC에서)
- [ ] `설정 → 앱`(또는 제어판)에서 제거 → 시작 메뉴·바탕화면 바로가기와 `%LOCALAPPDATA%\Programs\LyricsSlideCreator`가 없어짐

## 2. macOS

- [ ] `-macOS.zip` 압축 해제 → `Lyrics Slide Creator.app`을 응용 프로그램 폴더로 이동
- [ ] 실행 → 차단되면 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기 → 실행됨
- [ ] 버전 표시, 검색, 편집, 템플릿 변경, PPT 생성·확인 (Windows와 같은 항목)
- [ ] 다크 모드/라이트 모드 전환 시 화면이 자연스러움

## 3. 공개

- [ ] (첫 릴리스만) 릴리스 노트에 안내 추가: "v1.1-beta 이하를 쓰던 분은 이번 버전을 직접 한 번 설치해주세요. 이후부터는 앱에서 자동으로 업데이트됩니다."
- [ ] 초안에서 **Publish release** 클릭

문제가 있으면 공개하지 말고 초안과 태그를 지운 뒤(`git push origin :<태그>`) 고쳐서 다시 태그를 올립니다.
