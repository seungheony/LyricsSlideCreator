# 릴리스 체크리스트

베타로 먼저 배포해 직접 테스트하고, 문제가 없으면 같은 커밋에 정식 태그를 답니다.

CI가 매번 자동으로 확인하는 것: 빌드, 화면·폰트·템플릿 로드(`--self-test`), Windows 설치 → 실행 → 제거 후 남은 파일 없음.
여기서는 **사람이 실제로 써봐야 아는 것**을 확인합니다.

## 1. 베타 배포

- [ ] 배포할 내용이 master에 머지되어 있음
- [ ] `./scripts/release.sh` → `1) 베타 배포` → 버전 입력 (베타 번호는 자동. master가 아니거나 최신이 아니면 master로 바꾸고 pull할지 물음)
- [ ] Actions가 끝나면 [Releases](https://github.com/seungheony/LyricsSlideCreator/releases)에 프리릴리스와 파일 3개(`-Windows-Setup.exe`, `-macOS.zip`, `SHA256SUMS.txt`)가 있는지 확인

## 2. 업데이트 테스트 (Windows, macOS 각각)

이전 베타가 설치된 PC에서 진행합니다. (첫 베타라 이전 베타가 없으면 직접 설치하고 3번으로)

- [ ] 앱 실행 → 몇 초 안에 창 맨 위에 "v… 버전이 나왔어요" 알림 막대 (편집 머리글·곡 추가 서랍을 가리지 않고 아래로 밀어냄)
- [ ] `변경 내용`에 릴리스 노트가 보임 (기여자·PR 주소·feat: 같은 접두어 없이, 맨 아래 줄까지 스크롤됨)
- [ ] `업데이트` → 진행률 중 `취소` → 창이 닫히고 알림 막대가 다시 보임
- [ ] 알림 막대 ✕ → 오른쪽 위 버전 표시에 '새 버전 있음' → 누르면 업데이트 확인창
- [ ] `업데이트` → 진행률 → 앱이 닫혔다가 다시 켜짐 → "v… 버전으로 업데이트했어요" 알림
  - (Windows) 설치 진행 창이 잠깐 보였다가 앱이 다시 켜짐
  - (macOS) 예전 이름 '가사 슬라이드 생성기.app'에서 업데이트하면 'Lyrics Slide Creator.app'으로 바뀌고 예전 앱이 남지 않음 (v1.3.0 이하 앱에서 받은 첫 업데이트는 폴더 이름이 그대로고, 그다음 업데이트 때 바뀜)
- [ ] 다시 켜진 앱의 오른쪽 위 버전이 새 베타 버전

## 3. 기능 테스트 (업데이트된 앱으로, Windows·macOS 각각)

Windows 실기 확인 목록(줄바꿈 예측 비교, 해상도·배율, 업데이트·제거, 한글 입력): [WINDOWS_CHECK.md](WINDOWS_CHECK.md)

- [ ] 처음 실행: 곡 추가 서랍이 열린 채 시작하고 서랍 튜토리얼(4단계: 검색 → ＋로 담기 → 보관함·직접 입력 → 편집으로. 닫기·Esc 없음, `건너뛰기`만 가능) → 곡을 담고 서랍을 닫아 처음 곡이 열리면 편집 화면 튜토리얼(13단계, 첫 단계가 콘티) → 앱을 다시 실행하면 나오지 않음. 끝내거나 건너뛰면 "? 버튼으로 언제든 다시 볼 수 있어요" 안내가 뜸. 건너뛰면 편집 화면 튜토리얼도 나오지 않음
  - 기록은 앱 데이터 폴더의 `state.json`(Windows `%APPDATA%\LyricsSlideCreator`, macOS `~/Library/Application Support/LyricsSlideCreator`). 앱 안에는 파일이 생기지 않음(macOS `ls "<앱>/Contents/MacOS"`). 앱이 다시 실행이 잘 되는지
  - 업데이트한 뒤에도 튜토리얼이 다시 나오지 않음 (예전 macOS 앱의 plist 기록은 처음 실행 때 옮겨지고 `defaults read io.github.seungheony.lyricsslidecreator tutorials_seen`이 없다고 나옴)
- [ ] 창 크기·위치를 바꾸고(최대화 포함) 닫았다 열면 같은 자리·크기로 열림. 모니터를 뺀 뒤에는 기본 화면 가운데에 열림
- [ ] 프리셋: 편집 화면 아래 `프리셋` `저장`(⌘S/Ctrl+S) → 이름 입력(기본 오늘 날짜) → 서랍의 멜론 탭에서 같은 곡을 다시 검색하면 결과 옆 `프리셋 N` → 누르면 보관함 탭에 그 곡만 보임(`모든 프리셋`으로 전체) → ＋로 담으면 저장한 슬라이드 그대로(2줄 자동 나누기 없음). 삭제는 두 번 눌러야 지워짐. 업데이트한 뒤에도 남아 있음
  - 직접 입력한 곡: 프리셋 저장 → 제목으로 검색하면 결과 맨 위(음표 아이콘·'직접 입력'), 가사 검색으로도 나옴 → 누르면 보관함 탭에서 그 곡의 프리셋. 앱을 다시 켜도 찾아짐
  - 서랍 `보관함` 탭: 곡이 가나다순, 곡별 카드에 앨범아트가 보이고(직접 입력한 곡은 음표), 찾기·연필로 이름 고치기(Esc는 이름 고치기만 취소)·삭제가 됨(연필·휴지통은 줄에 마우스를 올려야 보임). 슬라이드는 줄을 눌러 펼쳐야 보이고, 길면 정해진 높이 안에서 스크롤됨
  - 보관함 추가/바꾸기: 콘티에 없는 곡은 ＋ → 콘티 끝에 더해지고 편집기는 그대로(서랍을 닫으면 그 곡이 열림). 콘티에 있는 곡은 '콘티 N번' 배지와 `이걸로 바꾸기` → 가사가 바뀌고 되돌리기 토스트(다른 곡이면 그 곡을 열어 되돌리기 가능)
  - 편집 화면 아래 `프리셋` `불러오기`: 서랍이 보관함 탭으로 열리고 편집 중인 곡이 맨 위에 '편집 중'
- [ ] 설치 폴더·앱 안에 `LICENSE`, `THIRD_PARTY_NOTICES.txt`가 있음
- [ ] 각 `?` 버튼: 설명할 부분만 밝아지고 예시 동작(가짜 포인터)이 실제 화면 위에서 재생됨, 가사는 바뀌지 않음
- [ ] 앱 이름이 'Lyrics Slide Creator' (창 제목·Dock/작업 표시줄·Windows 시작 메뉴·제어판), 앱 아이콘이 보임
  - (Windows) 업데이트 후 예전 '가사 슬라이드 생성기' 바로가기가 남지 않음
- [ ] 서랍 멜론 탭 검색 → 결과에 앨범아트가 보임
- [ ] 곡 담기 → 서랍을 닫으면 그 곡이 열리고 가사가 2줄씩 나뉘어 있음
- [ ] 편집: 줄 사이 ✂ 나누기, 슬라이드 사이 합치기, 슬라이드 삭제, ⌘Z/Ctrl+Z 되돌리기
- [ ] 줄 옮기기: 첫 줄 → 앞 슬라이드 끝, 마지막 줄 → 뒤 슬라이드 처음(3줄이 되면 3줄 그대로), 옆 사이에 새 슬라이드, 그 외 위치는 놓이지 않음
- [ ] `2줄 유지`가 처음부터 켜져 있음. 줄 옮기기: 넘친 줄은 연쇄로 밀리고, 줄을 준 슬라이드는 1줄로 남음(당겨 채우지 않음)
- [ ] `2줄 유지` 켜고 3줄이 되는 합치기 → 확인창 / 입력칸에 3줄 입력 후 입력칸 밖 클릭 → 확인창(2줄씩 나누기·그대로 두기)
- [ ] 하단에 '기본 템플릿 · 커스텀 템플릿은 추후 지원 예정' (변경 버튼 없음)
- [ ] 줄바꿈 경고: 긴 줄은 주황색 ⚠, `줄바꿈 N장`을 누르면 차례로 이동 → PPT를 만들어 PowerPoint에서 바로 그 줄들만 두 줄로 나뉘는지 (특히 Windows PowerPoint. 계산 규칙은 Mac PowerPoint에서만 확인함)
- [ ] `PPT 생성` → 저장 → 완료 알림
- [ ] 곡 추가 서랍: 콘티의 `곡 추가`·⌘K/Ctrl+K → 콘티 오른쪽에 서랍이 열리고 검색칸에 포커스. 결과의 ＋를 연달아 누르면 '받는 중' → '담음', 콘티 끝에 차례로 쌓이고 그동안 편집기는 바뀌지 않음. 아래 '이번에 N곡 담았어요'
  - `편집으로`·✕·Esc·바깥 클릭으로 닫으면 이번에 처음 담은 곡이 열림(아직 받는 중이면 다 받은 뒤). 담은 곡이 없으면 지금 곡 그대로
  - Esc 순서: 줄 드래그 중이면 드래그 취소 → 가사 칸에 있으면 칸에서 빠져나오기 → 서랍 닫기
  - 이미 콘티에 있는 곡은 '콘티에 있음', 가사를 받지 못하면 콘티에서 빠지고 오류 창('다시 시도'·'직접 입력으로 열기')
- [ ] 직접 입력 탭: 제목·가수·가사 → `콘티에 담기`(⌘↵/Ctrl+Enter) → 콘티 끝에 담기고 입력칸이 비워짐. '2줄씩 자동으로 나누기'를 끄면 입력한 그대로
  - 멜론 검색 결과 없음·검색 실패·가사 불러오기 실패의 `직접 입력으로 열기` → 이 탭에 제목(검색어)과 안내 문구가 미리 채워짐. 가사 불러오기 실패에서 온 곡은 앨범아트가 보임
- [ ] 콘티: 곡을 눌러 오가도 곡마다 가사·되돌리기·커서가 그대로, 끌어서 순서 바꾸기, 휴지통으로 빼기 → 되돌리기 토스트, 목록의 장 수·줄바꿈 장 수가 맞음
- [ ] 콘티 0곡: 마지막 곡을 빼면 빈 상태 안내와 함께 서랍이 열림. 첫 실행·다시 실행 때 콘티가 비어 있으면 서랍이 저절로 열림('어떤 곡으로 시작할까요?')
- [ ] 콘티 비우기: 콘티 머리의 ⋯ → `콘티 비우기` → 확인 없이 비워지고 서랍이 열림 → 토스트의 `되돌리기`로 곡·편집 내용이 그대로 돌아옴. 비운 뒤 같은 곡을 다시 담으면 이어서 편집
- [ ] 콘티 3곡으로 PPT 생성 → 기본 파일 이름 'YYYY-MM-DD 예배 가사', PowerPoint에서 처음·곡 사이·끝에 검은 빈 슬라이드, 곡 순서가 목록과 같음. 곡 하나면 '제목 — 가수', 빈 슬라이드는 처음·끝
- [ ] 콘티: 다른 곡에 3줄 슬라이드가 있으면 PPT 생성 전 확인창에 곡 제목과 번호가 나오고, '2줄씩 나누기'를 고르면 그 곡도 나뉨(그 곡을 열어 되돌리기 가능)
- [ ] 만든 PPT를 PowerPoint에서 열어 가사·줄 간격·Pretendard 서체 확인 (가능하면 Pretendard가 없는 PC에서)
- [ ] (macOS) 다크 모드/라이트 모드에서 화면 확인

문제가 있으면 고쳐서 master에 머지한 뒤 `./scripts/release.sh` → `1) 베타 배포`로 다음 베타(`v1.4-beta.2`)를 내고 1번부터 다시 합니다.

## 4. 정식 배포

- [ ] `./scripts/release.sh` → `2) 정식 배포` (마지막 베타와 **같은 커밋**에 정식 태그). 터미널을 닫지 말고 Actions가 끝날 때까지 기다림(20분쯤)
- [ ] 정식 릴리스와 파일 3개가 확인되면 이 버전의 베타 릴리스 목록이 나옴 → `y`로 지움 (git 태그는 남음)
  - 기다리다 멈췄거나 지우지 않았으면, 정식 릴리스가 올라간 뒤 `./scripts/release.sh` → `3) 베타 릴리스 정리`
- [ ] Releases 페이지에 정식 릴리스만 남았는지 확인 (같은 커밋에서 다시 빌드되며 CI 검증도 다시 실행됨)
- [ ] 릴리스 노트 확인 (이전 정식 버전 이후 변경 전체가 들어감, 필요하면 릴리스 페이지에서 수정)
- [ ] (첫 정식 릴리스만) 릴리스 노트에 안내 추가: "v1.1-beta 이하를 쓰던 분은 이번 버전을 직접 한 번 설치해주세요. 이후부터는 앱에서 자동으로 업데이트됩니다."
