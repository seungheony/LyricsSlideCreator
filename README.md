# 가사 슬라이드 생성기 (Lyrics Slide Creator)

가사 슬라이드 생성기는 Melon.com에서 노래 가사를 검색하고, 편집하여 PowerPoint 프레젠테이션 슬라이드로 자동 생성해주는 데스크톱 애플리케이션입니다. 교회, 학교, 행사 등에서 노래 가사를 효과적으로 전달해야 할 때 유용하게 활용할 수 있습니다.

## 주요 기능

*   **Melon.com 노래 검색**: 노래 제목 또는 가수 이름으로 검색하고 앨범아트와 함께 결과를 보여줍니다.
*   **가사 편집**: 빈 줄로 슬라이드를 나누는 가사 편집기와 실시간 슬라이드 미리보기. 미리보기에서 줄 사이를 눌러 나누기, 슬라이드 사이를 눌러 합치기, 줄을 옆 슬라이드로 끌어 옮기기, 되돌리기(⌘Z / Ctrl+Z)를 지원합니다.
*   **PowerPoint 생성**: 템플릿(`.pptx`) 서식을 그대로 유지한 채 가사 슬라이드를 만듭니다. 기본 템플릿과 앱 화면은 Pretendard 서체를 사용합니다.
*   **자동 업데이트**: 새 버전이 나오면 앱에서 알려주고, [업데이트] 버튼 하나로 받아서 설치·재시작합니다.
*   **깔끔한 설치/제거**: 앱은 설치 폴더(.app) 밖에 파일을 남기지 않으며, Windows에서는 제어판에서 제거하면 관련 파일이 모두 지워집니다.

## 설치 (사용자)

[Releases](https://github.com/seungheony/lyricsSlide_Creator/releases)에서 최신 버전을 받습니다.

*   **Windows**: `LyricsSlideCreator-<버전>-Setup.exe` 실행. 관리자 권한 없이 현재 사용자 계정에 설치됩니다. 제거는 `설정 → 앱` 또는 `제어판 → 프로그램 제거`에서 합니다.
    *   서명되지 않은 설치 파일이라 "Windows의 PC 보호" 창이 뜰 수 있습니다. **추가 정보 → 실행**을 누르면 설치됩니다.
*   **macOS (Apple Silicon, macOS 15 이상)**: `LyricsSlideCreator-<버전>-macOS.zip`을 풀고 `가사 슬라이드 생성기.app`을 **응용 프로그램 폴더로 옮긴 뒤** 실행합니다. 제거는 앱을 휴지통으로 옮기면 됩니다.
    *   서명되지 않은 앱이라 처음 실행하면 "열 수 없습니다" 경고가 뜹니다. **시스템 설정 → 개인정보 보호 및 보안**으로 가서 아래쪽의 **그래도 열기**를 누른 뒤 다시 실행하세요. 한 번만 하면 됩니다. (macOS 15부터는 우클릭 → 열기로는 실행되지 않습니다.)
    *   응용 프로그램 폴더로 옮기지 않고 다운로드 폴더에서 바로 실행하면 자동 업데이트가 동작하지 않습니다.

### PowerPoint 서체

기본 템플릿(`template.pptx`)에는 Pretendard 서체가 포함되어 있어, 발표하는 PC에 Pretendard가 없어도 PowerPoint에서 서체가 유지됩니다. (Keynote, Google Slides, 오래된 PowerPoint는 포함된 서체를 쓰지 않으므로 그 PC에 Pretendard를 설치해야 합니다.)

다른 템플릿을 쓸 때 같은 효과를 내려면, 그 템플릿을 PowerPoint에서 열고 **글꼴 포함 → 모든 문자 포함**으로 저장하세요 (Windows: 파일 → 옵션 → 저장 / macOS: PowerPoint → 설정 → 저장). 서체는 `.ttf`로 설치되어 있어야 포함할 수 있습니다.

## 개발

### 1. 종속성 설치

Python 3.12 이상이 필요합니다.

```bash
python -m venv venv
# Windows: .\venv\Scripts\activate
source venv/bin/activate
pip install -r requirements.txt
```

### 2. 개발 모드 실행

```bash
python run.py
```

개발 모드에서는 버전이 `TEST`로 표시되고 업데이트 확인을 하지 않습니다. `python run.py --self-test`는 화면·폰트·템플릿이 모두 로드되는지 점검하고 종료 코드로 결과를 알려줍니다.

### 3. 배포 빌드

```bash
python scripts/build.py 1.2.0
```

*   **macOS**: `dist/가사 슬라이드 생성기.app`, `dist/LyricsSlideCreator-1.2.0-macOS.zip`
*   **Windows**: `dist/LyricsSlideCreator-1.2.0-Setup.exe` ([Inno Setup 6](https://jrsoftware.org/isinfo.php) 필요)

Nuitka로 C 컴파일하므로 macOS는 Xcode Command Line Tools, Windows는 Visual Studio Build Tools(C++)가 필요합니다.

### 4. 작업 흐름

작업 브랜치에서 개발하고 master로 PR을 올려 머지합니다. 배포용 빌드와 검증은 PR에서는 하지 않고, 릴리스 태그를 올릴 때(`scripts/release.sh`) GitHub Actions가 합니다. 릴리스 없이 빌드만 시험하려면 Actions 탭의 Release 워크플로를 수동 실행(`Run workflow`)합니다.

### 5. 릴리스

베타로 먼저 배포해 직접 테스트하고, 문제가 없으면 같은 커밋을 정식으로 배포합니다. 배포는 최신 master에서 합니다. 다른 브랜치에서 실행하면 master로 바꾸고 최신으로 받을지(git pull) 묻고, 받은 뒤 진행합니다.

```bash
./scripts/release.sh beta 1.2.0     # v1.2.0-beta.1 (번호 자동) → 프리릴리스. 베타 사용자에게만 업데이트 알림
# 이전 베타가 설치된 PC에서 업데이트·기능 테스트 → 문제가 있으면 고친 뒤 다시 beta (v1.2.0-beta.2 ...)
./scripts/release.sh stable         # 마지막 베타와 같은 커밋에 v1.2.0 → 정식 릴리스. 모든 사용자에게 알림
                                    # 릴리스가 만들어질 때까지 기다린 뒤 v1.2.0 베타 릴리스를 지울지 묻는다
./scripts/release.sh clean-betas 1.2.0   # (stable에서 기다리다 멈췄을 때) 정식 릴리스 확인 후 베타 릴리스 지우기
```

테스트 항목은 [릴리스 체크리스트](docs/RELEASE_CHECKLIST.md)를 따릅니다. 스크립트는 태그를 올리기 전에 대상 커밋을 보여주고 확인을 받으며, 커밋하지 않은 변경이 있거나 로컬 master에 원격에 없는 커밋이 있거나 이미 배포된 버전이면 거부합니다.

정식 배포가 끝나면 그 버전의 베타 릴리스는 Releases 페이지에서 지웁니다(정식 릴리스가 파일과 함께 올라간 것을 확인한 뒤에만, 확인을 받고). git 태그는 남기며, 베타를 쓰던 사람은 정식 버전으로 그대로 업데이트됩니다. GitHub에서 공개 저장소의 릴리스는 누구에게나 보이므로, 베타는 테스트하는 동안만 Releases에 둡니다.

정식 릴리스 파일은 같은 커밋에서 다시 빌드됩니다(버전 번호가 앱에 들어가기 때문). 릴리스 노트는 머지된 PR 제목으로 자동 생성되며, 정식 릴리스는 이전 정식 버전 이후의 변경 전체를 담습니다.

## 사용 방법

처음 실행하면 화면마다 사용법 튜토리얼이 나옵니다. 각 부분 옆의 `?` 버튼을 누르면 언제든 다시 볼 수 있습니다.

1.  **노래 검색**: 검색창에 노래 제목이나 가수를 입력하고 `검색`을 누릅니다.
2.  **노래 선택**: 결과에서 노래를 누르면 가사가 2줄씩 나뉘어 편집 화면이 열립니다.
3.  **가사 편집**: 왼쪽 가사 입력칸에서 빈 줄로 슬라이드를 나누거나, 오른쪽 미리보기에서 나누기·합치기·줄 옮기기·삭제를 합니다. `자동 나누기`로 1줄 또는 2줄씩 다시 나눌 수 있습니다.
    *   **줄 옮기기**: 슬라이드의 첫 줄은 앞 슬라이드 끝이나 앞쪽 사이(새 슬라이드)로, 마지막 줄은 뒤 슬라이드 처음이나 뒤쪽 사이로 끌어 옮깁니다.
    *   **2줄 유지**(기본으로 켜져 있음): 켜면 슬라이드마다 2줄을 유지합니다. 옮겨서 2줄을 넘으면 넘친 줄이 같은 방향으로 연쇄해서 밀리고, 줄이 빠진 슬라이드는 이웃 슬라이드에서 연쇄로 당겨와 채웁니다. 2줄씩 묶인 경계를 한 줄씩 옮길 때 편리합니다. 켠 상태에서 `합치기`나 가사 입력으로 3줄 이상 슬라이드가 생기면 확인창으로 알려줍니다(입력은 입력칸에서 벗어날 때 한 번).
    *   **줄바꿈 경고**: 한 줄이 PPT 글상자 폭을 넘어 두 줄로 나뉠 줄은 미리보기에서 주황색 ⚠로 표시됩니다. 위쪽 `줄바꿈 N장`을 누르면 그 슬라이드를 차례로 보여줍니다.
4.  **템플릿**: 지금은 기본 템플릿으로 만듭니다. 직접 만든 템플릿은 추후 지원할 예정입니다.
5.  **PPT 생성**: `PPT 생성`(⌘Enter / Ctrl+Enter)을 눌러 저장합니다.

## 기술 스택

*   **PySide6 (Qt Quick / QML)**: 사용자 인터페이스
*   **requests, beautifulsoup4**: Melon.com 검색·가사 수집
*   **python-pptx**: PowerPoint 생성
*   **Nuitka, Inno Setup, GitHub Actions**: 빌드·설치 파일·자동 릴리스
